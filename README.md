# AI Project Submission Analyzer (AIPSA)

A pixel-perfect diagnostic engine for evaluating developer capabilities and project authenticity based on the Stitch UI/UX design.

## Features

- **Stage 1 (Upload)**: Drag & drop ZIP files, specify project title, description, outcomes, and select questions per skill.
- **Stage 2 (Analysis)**: Animated analysis pipeline displaying real-time metrics (detected dependencies, confidence, architecture, and technology badges).
- **Stage 3 (Viva Mode)**: Interactive interview layout featuring timers, expected answer reveals, grading options (Fail/Partial/Approve), live technical depth statistics, and suspicion indicators.
- **Stage 4 (Report)**: Comprehensive review featuring overall scores, verification grids, authenticity classifications (e.g. Production Ready), and JSON export.

## Technologies Used

- **React** (v18, functional hooks)
- **Vite** (Next-generation frontend tooling)
- **Tailwind CSS** (Utility-first styling matching Stitch palette)
- **React Router** (Stage flow navigation)
- **Framer Motion** (Subtle premium transitions)
- **Recharts** (Visual indicators & interactive analytics charts)
- **Lucide React** (Icons)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your web browser.
